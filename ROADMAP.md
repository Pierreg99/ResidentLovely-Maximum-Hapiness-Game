### Phase 1: Foundation & Gameplay Core (v1.0.0) ✔
- [x] Three.js WebGL scene with soft shadow maps and responsive viewport scaling.
- [x] Over-the-shoulder chase camera with aim zoom and laser sight line.
- [x] Multi-touch virtual analog joystick and tactile action buttons.
- [x] 8-slot inventory grid with item examination, usage, and combine recipes.
- [x] Pulse ECG Vitality monitor (MAX BLISS ➔ CHEERFUL ➔ GRUMPY).
- [x] Golden Gramophone save station with `localStorage` snapshotting.
- [x] Procedural Web Audio API sound effects.

- [x] Procedural Grand Concert Piano with playable keys and sound generator.

- [x] Alchemical Cauldron in East Wing Library with bubbling magenta brew.
- [x] 4 Heart Lanterns in West Wing Solarium Garden.
- [x] 3 distinct Grump variants: Gloom Bear, Sighing Specter, Gilded Knight.
- [x] Dedicated in-game Quest Log modal with live task progress ticks.

- [x] 4-Weapon arsenal: Confetti Pistol, Bubble Shotgun, Pastry Mortar, Prismatic Joy Beam.
- [x] Real-time 3D ballistic projectile simulation with gravity arcs and particle collisions.
- [x] Bubble trap physics: Bubble Shotgun lifts enemies into floating soap bubbles.
- [x] 360° Mortar explosion with camera recoil shake.
- [x] Continuous Prismatic Joy Beam laser with polyphonic audio hum.
- [x] Rotating Radar Mini-Map HUD with live entity blips.
- [x] Fullscreen Estate Blueprint map with dynamic lock states (Red/Green) and player marker.
- [x] Destructible Floating Balloons and Gilded Gift Boxes with treat drops.
