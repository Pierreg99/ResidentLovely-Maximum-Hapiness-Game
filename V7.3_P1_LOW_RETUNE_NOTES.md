# v7.3 P1 Low-Retune Notes

**Scope:** P1 only (Low-Retune). Overhaul = P1–P3; this PR does **not** complete the overhaul.

## Numeric Cap (Critic nit)

`PIXEL_BUDGET_CAP = 1600`

Mapping (High-first):

| Preset | Rule |
|--------|------|
| high | `width >= 1280 && dpr >= 2` |
| low | `width < 768` OR (`width < 1280 && width*dpr > 1600`) |
| med | else |

High-end phones are not forced Low solely via binary `isMobile`; narrow width and/or fill-rate budget decide Low. Retina desktops with `width >= 1280 && dpr >= 2` map to **high** before budget Low.
