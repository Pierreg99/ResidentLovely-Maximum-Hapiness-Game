# Resident Lovely — Maximum Happiness (R3F web port)

Playable over-the-shoulder 3D port of Chateau de la Joie.

## What landed

- **20 maps** with unique biomes and centerpieces (foyer, library, garden, tea salon, bakery, observatory, belfry, grotto, meadow, harbor, mirror maze, music parlor, village, forest, sugar lab, crypt, lighthouse, ice chamber, conservatory, terrace)
- **20 quests** including Maximum Happiness finale and Grand Gloom Behemoth
- **Kawaii 3D rigs** (Agent Joy twin-tails, glossy eyes, tactical vest; NPC variants; plush Grumps)
- Immersives: examine notes, lanterns, piano triad C-E-G, alchemy crafting, weather, door gating
- Tank controls: W/S walk, A/D turn left/right, mouse look, Space fire, E examine
- Touch sticks on phones, local save

This port lives in the Grok app builder runtime (TanStack Start + React Three Fiber). Source for the playable layer is under `r3f/`.
